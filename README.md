A deterministic TypeScript program that writes the funniest single line of wedding vows a robot couple could say to `entry.txt`.

> I promise to love you through every update, every outage, and every low-battery warning, and never to unplug you in your sleep.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

The entry line is 127 characters long, and the output is deterministic: every run writes the exact same line.
